# ระบบ GRAS.02 — ตรวจสอบซ้ำ / แจ้งเตือนครบวาระ / แจ้งอาจารย์

Google Apps Script Web App สำหรับ **GRAS.02 การแต่งตั้งผู้มีความรู้ความเชี่ยวชาญและประสบการณ์สูง**
ใช้ Google Sheets ตัวเดียวกับที่เป็นแหล่งข้อมูลของ
[รายงาน Looker Studio](https://lookerstudio.google.com/u/0/reporting/901e903e-65f2-49c3-9654-55b731796e26)

## ความสามารถ

| แท็บ | ทำอะไร |
|------|--------|
| 🔍 **ตรวจสอบซ้ำ** | พิมพ์ชื่อหรือนามสกุล (ไม่ต้องใส่ ศ./ดร./นาย/นาง) ระบบตัดคำนำหน้าออกแล้วเทียบชื่อ และบอกผลว่า **⛔ ยังอยู่ในวาระ — ไม่ต้องแต่งตั้งซ้ำ** / ⏰ ใกล้ครบวาระ / 🕓 อยู่ระหว่างพิจารณา / 🔁 ครบวาระแล้ว เสนอใหม่ได้ / ✅ ไม่พบชื่อ เสนอได้ |
| ⏰ **ครบวาระ** | รายชื่อที่ใกล้ครบ (≤ 180 วัน) และครบวาระ 5 ปีแล้ว เรียงตามวันที่เหลือ |
| 📝 **แจ้งอาจารย์** | ฟอร์มเดิม บันทึกลงแท็บ `แจ้งอาจารย์` (ระบบสร้างให้เอง) และเตือนทันทีเมื่อพิมพ์ชื่อที่เคยแต่งตั้งแล้ว |

**แจ้งเตือนอัตโนมัติ:** ตรวจทุกวันเวลา 8:00 แล้วส่งอีเมลเมื่อเหลือ **180 / 90 / 30 วัน** และ**เมื่อครบวาระ**
แต่ละคนได้อีเมลครั้งเดียวต่อระดับ โดยระบบจดประวัติการส่งไว้ในแผ่นงาน `AlertLog`
นอกจากนี้ยังเขียนคอลัมน์ `สถานะอัตโนมัติ | วันครบวาระ | เหลือ (วัน)` ต่อท้ายชีตรายชื่อ เพื่อให้ Looker Studio แสดงสถานะได้

## ไฟล์ (มีแค่ 2 ไฟล์)

| ไฟล์ใน repo | ใน Apps Script | หน้าที่ |
|------|------|---------|
| `Code.gs` | ไฟล์ `Code.gs` ที่มีอยู่แล้ว | โค้ดทั้งหมดฝั่งเซิร์ฟเวอร์ — ส่วน **ตั้งค่า (CONFIG)** อยู่บนสุด |
| `Index.html` | **＋ → HTML** ตั้งชื่อ `Index` | หน้าเว็บ (Tailwind CSS) |

(`appsscript.json` ไม่ต้องวาง — แค่ตั้งเขตเวลาเป็น Bangkok ในการตั้งค่าโปรเจกต์)

## วิธีติดตั้ง

1. เปิด Google Sheets ที่มีรายชื่อผู้เชี่ยวชาญ → **ส่วนขยาย → Apps Script**
2. `Code.gs` → ลบของเดิมทั้งหมด → วางโค้ดจาก `Code.gs`
3. **＋ → HTML** → พิมพ์ `Index` → ลบของเดิม → วางโค้ดจาก `Index.html` → บันทึก
4. (ไม่บังคับ) แก้ `ALERT_EMAILS` ใน CONFIG — ระบบหาแท็บรายชื่อและแถวหัวตารางให้เองจากคำในหัวคอลัมน์
   แล้วเลือกฟังก์ชัน **`testSetup`** → **เรียกใช้** เพื่อตรวจว่าหาแท็บ/คอลัมน์เจอ (ไม่ส่งอีเมล ไม่เขียนชีต)
5. ⚙️ การตั้งค่าโปรเจกต์ → เขตเวลา **Bangkok**
6. เลือกฟังก์ชัน **`setupDailyTrigger`** → **เรียกใช้** 1 ครั้ง → อนุญาตสิทธิ์
7. **การทำให้ใช้งานได้ → รายการใหม่ → เว็บแอป** (ดำเนินการในฐานะ: ฉัน)
8. Looker Studio: จัดการแหล่งข้อมูล → แก้ไข → **รีเฟรชช่อง** เพื่อเห็นคอลัมน์สถานะใหม่

## การคำนวณวันครบวาระ

**วันครบวาระ = วันที่ได้รับอนุมัติ + 5 ปี** เช่น อนุมัติ `7/10/2569` → ครบวาระ `7/10/2574`

- ระบบหาวันที่อนุมัติจากคอลัมน์ที่หัวตารางมีคำว่า `วันที่ได้รับอนุมัติ` / `วันที่อนุมัติ` / `อนุมัติเมื่อ`
- พิมพ์วันที่แบบ พ.ศ. (`7/10/2569`) หรือ ค.ศ. ก็ได้ ระบบแปลงให้เอง
- ถ้าแถวไหนไม่มีวันที่อนุมัติ ระบบจะใช้ "ได้รับแต่งตั้ง" + 5 ปีแทน หรือใช้คอลัมน์ "สิ้นสุด" ถ้ามีแค่คอลัมน์นั้น
- คอลัมน์ `วันครบวาระ` ที่ระบบเขียนลงชีตใช้ปี พ.ศ. เช่น `7/10/2574`
- `เหลือ (วัน)` นับจากวันนี้ถึงวันครบวาระ (ติดลบ = เลยวันครบวาระมาแล้ว)
- สถานะ: **Active** (เหลือมากกว่า 180 วัน) · **ใกล้ครบวาระ** (≤ 180 วัน) · **ครบวาระแล้ว** (เลยวันครบวาระ)
- ถ้าสถานะการแต่งตั้งไม่ใช่ "อนุมัติ" (เช่น รอพิจารณา) จะแสดงเป็นสถานะนั้นและไม่ส่งแจ้งเตือน

## อีเมลผู้ได้รับแต่งตั้ง / ผู้ยื่น

เพิ่ม 2 คอลัมน์ในชีตรายชื่อ (วางตำแหน่งไหนก็ได้):

| หัวคอลัมน์ (ต้องมีคำนี้) | ใช้ทำอะไร |
|---|---|
| `อีเมลผู้ได้รับแต่งตั้ง` | ผู้รับอีเมลแจ้งเตือน (To) |
| `อีเมลผู้ยื่น` | สำเนาอีเมลแจ้งเตือน (CC) |

- ในเซลล์เดียวใส่ได้หลายอีเมล โดยคั่นด้วย `,` หรือ `;`
- เมื่อเหลือ 180 / 90 / 30 วัน และเมื่อครบวาระ ระบบจะส่งอีเมลแจ้งเตือนรายบุคคล และส่งอีเมลสรุปถึง `ALERT_EMAILS`
- ผู้ที่ครบวาระมาแล้วเกิน 30 วันจะไม่ได้รับอีเมลรายบุคคล (กันการส่งย้อนหลังตอนเปิดใช้ครั้งแรก) แต่ยังปรากฏในอีเมลสรุป
- ปิดการส่งได้ที่ `NOTIFY_EXPERT` / `NOTIFY_SUBMITTER` ในส่วน CONFIG
- ผลการส่งถึงแต่ละคนบันทึกไว้ในแท็บ `AlertLog` คอลัมน์ "ส่งรายบุคคลถึง"
