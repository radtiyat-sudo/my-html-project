# ระบบแจ้งอาจารย์ — GRAS.02

Web App (Google Apps Script) สำหรับบันทึกและแสดงข้อมูลการแจ้งอาจารย์ กรณียื่น
**GRAS.02 การแต่งตั้งผู้มีความรู้ความเชี่ยวชาญและประสบการณ์สูง**
([รายงาน Looker Studio](https://lookerstudio.google.com/u/0/reporting/901e903e-65f2-49c3-9654-55b731796e26))
โดยเก็บข้อมูลไว้ใน Google Sheets แผ่นงาน `Sheet1`

## ไฟล์

| ไฟล์ | หน้าที่ |
|------|---------|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: `doGet()` แสดงหน้าเว็บ, `saveData()` บันทึกแถวใหม่, `getData()` ดึงประวัติ |
| `Index.html` | หน้าเว็บ (Tailwind CSS): ฟอร์ม, Toast แจ้งเตือน, ตารางประวัติพร้อมค้นหาและรีเฟรชอัตโนมัติทุก 15 วินาที |

## คอลัมน์ใน Sheet1 (สร้างหัวตารางให้อัตโนมัติ)

`เวลาที่บันทึก | วันที่ | ชื่อ-นามสกุล | รายละเอียด / หมายเหตุ | จำนวนเงิน`

## วิธีติดตั้ง

1. สร้าง Google Sheets ใหม่ (หรือเปิดไฟล์ที่ต้องการ)
2. เมนู **ส่วนขยาย → Apps Script**
3. วางโค้ดจาก `Code.gs` ลงในไฟล์ `Code.gs`
4. กด **+ → HTML** ตั้งชื่อไฟล์ว่า `Index` (ไม่ต้องใส่ .html) แล้ววางโค้ดจาก `Index.html`
5. กด **บันทึก**
6. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (หรือ "ทุกคนในองค์กร" ตามต้องการ)
7. กด **ทำให้ใช้งานได้** → อนุญาตสิทธิ์ → คัดลอก URL เว็บแอปไปใช้งาน

> แก้ไขโค้ดภายหลัง ต้องไปที่ **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชัน: เวอร์ชันใหม่** เพื่ออัปเดต URL เดิม
