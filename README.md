# ระบบ GRAS.02 — ตรวจสอบซ้ำ / แจ้งเตือนครบวาระ / แจ้งอาจารย์

Google Apps Script Web App สำหรับ **GRAS.02 การแต่งตั้งผู้มีความรู้ความเชี่ยวชาญและประสบการณ์สูง**
ใช้ Google Sheets ตัวเดียวกับที่เป็นแหล่งข้อมูลของ
[รายงาน Looker Studio](https://lookerstudio.google.com/u/0/reporting/901e903e-65f2-49c3-9654-55b731796e26)

## ความสามารถ

| แท็บ | ทำอะไร |
|------|--------|
| 🔍 **ตรวจสอบซ้ำ** | พิมพ์ชื่อหรือนามสกุล (ไม่ต้องใส่ ศ./ดร./นาย/นาง) ระบบตัดคำนำหน้าออกแล้วเทียบชื่อ และบอกผลว่า **⛔ ยังอยู่ในวาระ — ไม่ต้องแต่งตั้งซ้ำ** / ⏰ ใกล้ครบวาระ / 🕓 อยู่ระหว่างพิจารณา / 🔁 ครบวาระแล้ว เสนอใหม่ได้ / ✅ ไม่พบชื่อ เสนอได้ |
| ⏰ **ครบวาระ** | รายชื่อที่ใกล้ครบ (≤ 180 วัน) และครบวาระ 5 ปีแล้ว เรียงตามวันที่เหลือ |
| 📝 **แจ้งอาจารย์** | ฟอร์มเดิม บันทึกลง `Sheet1` และเตือนทันทีเมื่อพิมพ์ชื่อที่เคยแต่งตั้งแล้ว |

**แจ้งเตือนอัตโนมัติ:** ตรวจทุกวันเวลา 8:00 แล้วส่งอีเมลเมื่อเหลือ **180 / 90 / 30 วัน** และ**เมื่อครบวาระ**
แต่ละคนได้อีเมลครั้งเดียวต่อระดับ โดยระบบจดประวัติการส่งไว้ในแผ่นงาน `AlertLog`
นอกจากนี้ยังเขียนคอลัมน์ `สถานะอัตโนมัติ | วันครบวาระ | เหลือ (วัน)` ต่อท้ายชีตรายชื่อ เพื่อให้ Looker Studio แสดงสถานะได้

## ไฟล์ (มีแค่ 2 ไฟล์)

| ไฟล์ใน repo | ใน Apps Script | หน้าที่ |
|------|------|---------|
| `Code.gs` | ไฟล์ `Code.gs` ที่มีอยู่แล้ว | โค้ดทั้งหมดฝั่งเซิร์ฟเวอร์ — ส่วน **ตั้งค่า (CONFIG)** อยู่บนสุด |
| `Index.html` | **＋ → HTML** ตั้งชื่อ `Index` | หน้าเว็บ (Tailwind CSS) |

(`appsscript.json` ไม่ต้องวาง — แค่ตั้งเขตเวลาเป็น Bangkok ในการตั้งค่าโปรเจกต์)

## วิธีติดตั้ง

1. เปิด Google Sheets ที่มีรายชื่อผู้เชี่ยวชาญ → **ส่วนขยาย → Apps Script**
2. `Code.gs` → ลบของเดิมทั้งหมด → วางโค้ดจาก `Code.gs`
3. **＋ → HTML** → พิมพ์ `Index` → ลบของเดิม → วางโค้ดจาก `Index.html` → บันทึก
4. แก้ส่วน CONFIG บนสุดของ `Code.gs`: `EXPERT_SHEET_NAME` (ชื่อแท็บรายชื่อ) และ `ALERT_EMAILS`
5. ⚙️ การตั้งค่าโปรเจกต์ → เขตเวลา **Bangkok**
6. เลือกฟังก์ชัน **`setupDailyTrigger`** → **เรียกใช้** 1 ครั้ง → อนุญาตสิทธิ์
7. **การทำให้ใช้งานได้ → รายการใหม่ → เว็บแอป** (ดำเนินการในฐานะ: ฉัน)
8. Looker Studio: จัดการแหล่งข้อมูล → แก้ไข → **รีเฟรชช่อง** เพื่อเห็นคอลัมน์สถานะใหม่

## การคำนวณวันครบวาระ

- ค่า "ภาค/ปีการศึกษา" แปลงเป็นวันที่ดังนี้: ภาค 1 = ส.ค.–ธ.ค., ภาค 2 = ม.ค.–พ.ค. ของปีถัดไป, ภาคฤดูร้อน = มิ.ย.–ก.ค.
  - ตัวอย่าง: สิ้นสุด `2/2573` → ครบวาระ **31 พ.ค. 2574**
  - แก้ได้ที่ `SEMESTER_START` / `SEMESTER_END`
- คอลัมน์ "สิ้นสุด" อาจเป็นวันที่ เช่น `31/05/2574` ก็ได้
- ถ้าคอลัมน์ "สิ้นสุด" ว่าง ระบบจะนับ 5 ปีจากวันที่ได้รับแต่งตั้ง
- สถานะการแต่งตั้งที่ไม่ใช่ "อนุมัติ" (เช่น รอพิจารณา) จะแสดงเป็นสถานะนั้นและไม่ส่งแจ้งเตือน
