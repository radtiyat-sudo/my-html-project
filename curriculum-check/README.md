# ระบบตรวจโครงสร้างหลักสูตร

Google Apps Script Web App สำหรับเจ้าหน้าที่การศึกษา ใช้ตรวจว่านักศึกษาเรียนครบตามเล่มหลักสูตร (มคอ.2) หรือยัง โดยไม่ต้องไล่ตรวจเอง

## ใช้งาน 3 ขั้น

| ขั้น | ทำอะไร |
|------|--------|
| ① เล่มหลักสูตร | อัปโหลด PDF เล่มหลักสูตร **ครั้งเดียวต่อหลักสูตร** แล้วตรวจทานหมวด/หน่วยกิตและบันทึก ครั้งต่อไปเลือกจากรายการได้เลย |
| ② ข้อมูลนักศึกษา | ลากไฟล์มาวางได้หลายไฟล์พร้อมกัน: **PDF** ใบผลการเรียน (1 คน/ไฟล์) หรือ **Excel / CSV** ที่ export จากระบบทะเบียน (1 ไฟล์มีหลายคนได้) |
| ③ ผลการตรวจ | ตารางสรุปทุกคน ✓ ครบ / ⏳ รอผล / ✗ ยังไม่ครบ พร้อมบอกว่าขาดอะไร คลิกชื่อเพื่อดูรายละเอียด แล้วกด **บันทึกผลทุกคนลง Sheet** |

ระบบเลือกเล่มให้นักศึกษาแต่ละคนเองจาก **รหัสหลักสูตร** (เช่น `6736065 DTOP/M`) หรือชื่อสาขาวิชา ถ้าหาไม่เจอจะใช้เล่มที่เลือกไว้ในขั้นที่ ①

รายละเอียดของนักศึกษาแต่ละคนจะแสดง **“สิ่งที่ต้องตรวจสอบ / ดำเนินการ”** ได้แก่:
หมวดที่หน่วยกิตยังไม่ครบและวิชาในเล่มที่ยังไม่ได้เรียน · วิชาที่ไม่ผ่าน · วิชาที่รอผล · รหัสวิชาที่ไม่มีในเล่ม · หน่วยกิตในใบผลการเรียนที่ไม่ตรงกับเล่ม
ส่วนที่ซ่อนไว้ (คลิกเพื่อเปิด) ได้แก่ ไล่ตรวจทุกรายวิชาในเล่ม (ติ๊ก “โอน” ได้), เปลี่ยนหมวดของรายวิชา และตัวเลขสำหรับกรอกในระบบทะเบียน

### หัวคอลัมน์ Excel / CSV ที่ระบบอ่านได้
ต้องมี **รหัสวิชา** และ **หน่วยกิต** (หรือ **เกรด**) — คอลัมน์อื่นไม่บังคับ: รหัสนักศึกษา, ชื่อ-สกุล, รหัสหลักสูตร, สาขาวิชา, แผนการศึกษา, ปีการศึกษา / ภาคการศึกษา (หรือ ภาค/ปี), ชื่อวิชา
หัวตารางไม่จำเป็นต้องอยู่แถวแรก และข้อมูลนักศึกษาที่อยู่เหนือหัวตาราง (เช่น `รหัสนักศึกษา 6736065 DTOP/M`) ก็อ่านได้

## ติดตั้ง

1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก `Code.gs` ลงในไฟล์ `Code.gs`
3. **＋ → HTML** ตั้งชื่อ `Index` → วางโค้ดจาก `Index.html` → บันทึก
4. **การทำให้ใช้งานได้ → รายการใหม่ → เว็บแอป** (ดำเนินการในฐานะ: ฉัน)

ระบบสร้างแผ่นงาน `หลักสูตร`, `รายวิชาในหลักสูตร`, `ผลการตรวจ` ให้เอง
