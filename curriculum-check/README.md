# ระบบตรวจโครงสร้างหลักสูตร

Web App (Google Apps Script) สำหรับเจ้าหน้าที่การศึกษา: วางไฟล์นักศึกษา + เล่มหลักสูตร แล้วระบบจะ
**ใส่หมวดวิชาให้ทุกรายวิชา** และ **คำนวณตัวเลขช่องโครงสร้างหลักสูตร** ให้ พร้อมบอกว่านักศึกษาเรียนครบตามเล่มหรือยัง
เจ้าหน้าที่แค่นำไปกรอกในระบบงานสารสนเทศฯ บัณฑิตวิทยาลัย ไม่ต้องเปิดเล่มไล่ดูเอง

## วิธีใช้

1. ในระบบงานสารสนเทศฯ เปิดหน้าโครงสร้างหลักสูตรของนักศึกษา → **พิมพ์เป็น PDF** (หน้าที่ยังไม่กรอกหมวด)
2. ลากไฟล์นั้นกับ **PDF เล่มหลักสูตร (มคอ.2)** มาวางในช่องเดียวกันได้เลย ระบบแยกเองว่าไฟล์ไหนเป็นอะไร
3. ระบบแสดง
   - ✓ เรียนครบ / ✗ ยังไม่ครบ (บอกหมวดที่ขาดและรายวิชาที่ยังไม่เรียน) / ⏳ รอผลประเมิน
   - ตารางรายวิชาเหมือนหน้าระบบ โดยแสดง **หมวดเป็นตัวสีแดง** ให้เลือกตามในระบบ (ถ้าไม่ถูกต้องคลิกแก้ได้)
   - ช่อง **โครงสร้างหลักสูตร**: ช่องแรก = หน่วยกิตตามเล่มหลักสูตร (แผนของนักศึกษา) · ช่อง “เรียน” = ที่นักศึกษาเรียน · ช่อง “โอน” — คลิกที่ช่องเพื่อคัดลอก

**เล่มที่เป็นไฟล์สแกน** (PDF ที่แต่ละหน้าเป็นรูป): วางได้ตามปกติ ระบบอ่านด้วย OCR ให้เองทีละหน้า และหยุดเมื่อพ้นหน้ารายวิชาในหลักสูตร (ต้องเปิดบริการ Drive API ตามขั้นตอนติดตั้ง)

**เล่มเป็นรูปภาพก็ได้**: แคปหน้าจอหน้า “โครงสร้างหลักสูตร” และหน้า “รายวิชาในหลักสูตร” ของเล่ม แล้วกด **Ctrl+V** วางในหน้าเว็บทีละรูป (หรือลากไฟล์ PNG/JPG มาวาง)
ระบบอ่านตัวอักษรในรูปด้วย OCR ของ Google Drive แล้วแสดง **“เกณฑ์ตามเล่ม”** ให้ตรวจ — ถ้าตัวเลขผิดแก้ในช่องได้เลย

**เล่มหลักสูตรวางครั้งเดียวพอ** ระบบบันทึกเล่มไว้ตามรหัสหลักสูตร (เช่น `MSMS/M`, `DTOP/M`)
ครั้งต่อไปถ้าเป็นนักศึกษาหลักสูตรเดียวกัน วางแค่ไฟล์นักศึกษาก็พอ วางหลายไฟล์พร้อมกันก็ได้ (สลับดูทีละคนจากแถบรายชื่อ)

หลักการนับ (แบบเดียวกับที่กรอกในระบบ)
- **ตรวจตามแผนการศึกษาของนักศึกษา** (ก1 / ก2 / ข / 1.1 / 2.1 …) — เล่มที่มีหลายแผน ระบบใช้หน่วยกิตของแผนที่ตรงกับหน้านักศึกษา
- ปรับพื้นฐานไม่นับหน่วยกิต (ช่องเว้นว่าง)
- **GRID… = ภาษาอังกฤษ** ไม่ต้องเลือกหมวด ไม่นับหน่วยกิต
- วิทยานิพนธ์ที่ลงหลายภาค นับครั้งเดียว ตามหน่วยกิตที่ลงทะเบียน: **6 = สารนิพนธ์ · 12 = วิทยานิพนธ์ · 36 = วิทยานิพนธ์ ปริญญาเอก**
- ถ้าไฟล์นักศึกษามีหมวดที่กรอกไว้แล้ว ระบบจะเตือนเมื่อหมวดนั้นไม่ตรงกับเล่ม
- วิชาที่ยังไม่เรียนแต่ได้รับการเทียบโอน/ยกเว้น: ติ๊ก “โอน” ในส่วน “ดูการไล่ตรวจกับเล่ม”

## ติดตั้ง

1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก `Code.gs` ลงในไฟล์ `Code.gs`
3. **＋ → HTML** ตั้งชื่อ `Index` → วางโค้ดจาก `Index.html` → บันทึก
4. (สำหรับอ่านเล่มจากรูปภาพ) ในหน้า Apps Script กด **บริการ ＋** (แถบซ้าย) → เลือก **Drive API** → **เพิ่ม**
5. **การทำให้ใช้งานได้ → รายการใหม่ → เว็บแอป** (ดำเนินการในฐานะ: ฉัน)

ระบบสร้างแผ่นงาน `หลักสูตร` และ `รายวิชาในหลักสูตร` สำหรับเก็บเล่มให้เอง
