## 1. สรุป Graduate Student Journey จากเว็บไซต์

### 1.1 เส้นทางทั้ง 3 แผน (ตามเว็บไซต์)

| ลำดับ | ป.เอก | ป.โท แผน ก (วิทยานิพนธ์) | ป.โท แผน ข (สารนิพนธ์ / IS) |
|---|---|---|---|
| 1 | **บฑ.35** สอบวัดคุณสมบัติ (QE) | ลงทะเบียนวิทยานิพนธ์ | ลงทะเบียนสารนิพนธ์ / การค้นคว้าอิสระ |
| 2 | ลงทะเบียนวิทยานิพนธ์ | การได้มาซึ่งหัวข้อ (Optional) บฑ.39 / บฑกศ.39 | การได้มาซึ่งหัวข้อ (Optional) |
| 3 | การได้มาซึ่งหัวข้อ (Optional) บฑ.39 / บฑกศ.39 | **บฑ.1** อนุมัติหัวข้อ + แต่งตั้งกรรมการที่ปรึกษา | **บฑ.1** |
| 4 | **บฑ.1** อนุมัติหัวข้อ + แต่งตั้งกรรมการที่ปรึกษา | ดำเนินการวิจัย จริยธรรม และเก็บข้อมูล (IRB) | ดำเนินการวิจัย จริยธรรม และเก็บข้อมูล |
| 5 | ดำเนินการวิจัย จริยธรรม และเก็บข้อมูล (IRB) | **บฑ.2** สอบวิทยานิพนธ์ (หลัง บฑ.1 ≥ 90 วัน) | **บฑ.27** สอบประมวลความรู้ |
| 6 | **บฑ.2** สอบวิทยานิพนธ์ (หลัง บฑ.1 ≥ 90 วัน) | ส่งรูปเล่มอิเล็กทรอนิกส์ (21 วัน) | **บฑ.2** สอบสารนิพนธ์ / IS (หลัง บฑ.1 ≥ 45 วัน) |
| 7 | ส่งรูปเล่มอิเล็กทรอนิกส์ (21 วัน) | **บฑ.5** ยื่นขอสำเร็จการศึกษา | ส่งรูปเล่มอิเล็กทรอนิกส์ (21 วัน) |
| 8 | **บฑ.5** ยื่นขอสำเร็จการศึกษา | — | **บฑ.5** |

### 1.2 รายละเอียดแต่ละขั้นตอน (เงื่อนไข / เอกสาร / เวลา / ผลลัพธ์)

**A. บฑ.35 การสอบวัดคุณสมบัติ (Qualifying Examination) — ป.เอก เท่านั้น**
- นักศึกษา ป.เอก ทุกคนต้องสอบ และต้องได้ผล “ผ่าน” จึงจะยื่น บฑ.1 ได้
- คุณสมบัติผู้เข้าสอบ: ศึกษารายวิชาหรือสะสมหน่วยกิตครบตามหลักสูตร, ลงทะเบียนและชำระค่าธรรมเนียมสอบแล้ว, ประธานหลักสูตรเห็นชอบก่อนวันสอบ ≥ 15 วัน
- รูปแบบ: ข้อเขียน / ปากเปล่า / ทั้งสองอย่าง ตามที่หลักสูตรกำหนด; ตัดสินในการประชุมลับ ผล “ผ่าน/ไม่ผ่าน”
- กรรมการสอบ ≥ 3 ท่าน (ประธาน 1 + กรรมการ ≥ 2)
- เอกสาร: คำร้อง บฑ.35 (e-Form), เอกสารประกอบ/เค้าโครงการสอบ (ถ้ามี), รายงานผลสอบ
- แจ้งผลไปบัณฑิตวิทยาลัยภายใน 15 วันทำการ
- ไม่ผ่านครั้งแรก → สอบแก้ตัวได้อีก 1 ครั้ง ภายใน 180 วัน; ไม่ผ่านครั้งที่ 2 → เสนอให้พ้นสภาพ หรือเปลี่ยนระดับเป็น ป.โท

**B. ลงทะเบียนวิทยานิพนธ์ / สารนิพนธ์ / IS** — “ลงทะเบียนตามแผนการศึกษา” ผ่านระบบลงทะเบียน (รายละเอียดอื่น: ไม่พบข้อมูล)

**C. การได้มาซึ่งหัวข้อ (Optional) — บฑ.39 / บฑกศ.39**
- บฑ.39 (ขอสอบโครงร่าง + แต่งตั้งกรรมการสอบโครงร่าง) สำหรับรหัส 66 ลงมา; ป.เอก ต้องผ่าน QE แล้ว; กรรมการ ป.โท ≥ 2, ป.เอก ≥ 3; ประธานหลักสูตรเห็นชอบก่อนสอบ ≥ 15 วัน; ผล: ผ่าน → บฑ.1 / ผ่านแบบมีเงื่อนไข → แก้แล้วส่ง บฑ.37 / ไม่ผ่าน → ยื่นสอบใหม่
- บฑกศ.39 (ขอหนังสือเชิญผู้ทำหน้าที่ประเมิน/สอบโครงร่าง) รหัส 67 ขึ้นไปต้องใช้แบบนี้เท่านั้น; ผู้ทำหน้าที่ ป.โท ≤ 3, ป.เอก ≤ 5; ทำได้หลายรูปแบบ เช่น วิพากษ์ ประชุม หรือสอบ — อยู่ในการกำกับของหลักสูตร (ข้อบังคับฯ 2567 ข้อ 99 (5))

**D. บฑ.1 อนุมัติหัวข้อ + แต่งตั้งคณะกรรมการที่ปรึกษา**
- ป.เอก ต้องผ่าน QE ก่อน; ประธานหลักสูตรเห็นชอบการลงทะเบียนวิทยานิพนธ์แล้ว
- **ต้องเสนอหัวข้อภายใน 2 ภาคการศึกษา** นับจากเริ่มลงทะเบียนวิทยานิพนธ์
- กรรมการที่ปรึกษา: ป.โท ≥ 2 (หลัก 1 + ร่วม ≥ 1), ป.เอก ≥ 3 (หลัก 1 + ร่วม ≥ 2)
- เอกสาร: คำร้อง บฑ.1 (e-Form), CV ของที่ปรึกษาร่วมที่เป็นผู้ทรงคุณวุฒิภายนอก
- ชื่อเรื่องภาษาอังกฤษพิมพ์ UPPERCASE; ตรวจชื่อด้วย MUGR AI: Thesis Title & Abstract Enhancer (ทางเลือก)
- ลำดับอนุมัติ: นักศึกษา → ประธานหลักสูตร/คณะ → บัณฑิตวิทยาลัย
- หลังจากนั้น: **รายงานความก้าวหน้าทุกภาคการศึกษา (บฑ.42) ประเมินเป็น P / S / U**; เปลี่ยนหัวข้อ/ชื่อเรื่องใช้ บฑ.49

**E. ดำเนินการวิจัย จริยธรรม และเก็บข้อมูล**
- อบรมจริยธรรมการวิจัยในคน — ใบประกาศมีอายุ 2 ปี
- ยื่น IRB — **ต้องได้การรับรองก่อนเริ่มเก็บข้อมูล**
- ขอหนังสืออนุญาตลงพื้นที่เก็บข้อมูล (ถ้ามี) — บฑ.28; เชิญผู้เชี่ยวชาญตรวจเครื่องมือวิจัย — บฑ.30
- งานที่ไม่เข้าข่ายวิจัยในคน/สัตว์ → ทำ Human Research Checklist / แบบประเมินตนเองจากระบบ CIRB
- COA (หนังสือรับรองจริยธรรม) แนบหลัง บฑ.1 ได้รับอนุมัติ (PDF จากระบบ IRB ต้องเอารหัสผ่านออก)

**F. บฑ.27 สอบประมวลความรู้ — ป.โท แผน ข เท่านั้น**
- ศึกษารายวิชาและหน่วยกิตครบ, ชำระค่าธรรมเนียมแล้ว, กรรมการ ≥ 3, เห็นชอบก่อนสอบ ≥ 15 วัน
- ต้องผ่านก่อนยื่น บฑ.2; ไม่ผ่าน → ยื่นสอบได้จนกว่าจะผ่าน

**G. บฑ.2 สอบวิทยานิพนธ์ / สารนิพนธ์ (Final Oral Defense)**
- เงื่อนไข: เรียนรายวิชาครบ; ป.เอก ผ่าน QE; แผน ข ผ่านประมวลความรู้; **หลังอนุมัติหัวข้อ (บฑ.1) ≥ 90 วัน (วิทยานิพนธ์) / ≥ 45 วัน (สารนิพนธ์/IS)**; กรรมการที่ปรึกษาเห็นชอบให้สอบ
- คำร้องต้องได้รับความเห็นชอบ **ก่อนวันสอบ ≥ 15 วันติดต่อกัน**; ควรเผื่อเวลาให้บัณฑิตวิทยาลัยอีก 5–14 วันทำการ
- ส่งร่างเล่มให้กรรมการอ่าน **ล่วงหน้า ≥ 15 วัน**
- กรรมการสอบ: ป.โท ≥ 3; ป.เอก ≥ 4 (เกณฑ์ 2548) / ≥ 5 (เกณฑ์ 2558/2565); เกณฑ์ 2565 ต้องมีผู้ทรงคุณวุฒิภายนอกเป็นประธาน 1 + กรรมการ 1; **ที่ปรึกษาหลัก/ร่วมเป็นประธานสอบไม่ได้**
- เอกสาร: คำร้อง บฑ.2, ร่างเล่ม PDF, COA หรือ Self-assessment จาก CIRB
- ลงมติในการประชุมลับ เสียงข้างมาก; ประธานแจ้งผลเป็นลายลักษณ์อักษรภายใน 5 วัน; รายงานผลถึงบัณฑิตวิทยาลัยภายใน 15 วันทำการ
- ผล: **ผ่าน** → ส่งเล่มภายใน 21 วัน / **ผ่านโดยมีเงื่อนไข** → แก้ภายใน ≤ 90 วัน, ประธานสอบรับรอง บฑ.4 (วันที่บน บฑ.4 = วันแรกของ 21 วัน) / **ไม่ผ่าน** → ลงทะเบียนและชำระค่าสอบใหม่; ไม่ผ่านรอบ 2 → ทำหัวข้อใหม่
- ข้อควรรู้: คะแนนภาษาอังกฤษยังไม่ผ่านหรือเกรดยังไม่ครบ ยังยื่นสอบได้ แต่อาจกระทบ บฑ.5

**H. ส่งรูปเล่มอิเล็กทรอนิกส์ (e-Thesis)**
- ส่งภายใน **21 วัน** นับวันสอบผ่านเป็นวันแรก นับต่อเนื่องไม่เว้นวันหยุด
- ค่าปรับ (รวมกัน ไม่มีเพดาน): วันที่ 22–90 = 200 บาท/วันทำการ; วันที่ 91 ขึ้นไป = 400 บาท/วันทำการ
- ขั้นตอน: (1) กรอก Abstract Submission Form → (2) อัปโหลดเล่มฉบับสมบูรณ์ PDF ไฟล์เดียว (เว้นช่องลงนาม) + Turnitin Report → รอที่ปรึกษาหลัก + ประธานหลักสูตร “อนุมัติ” → (3) บัณฑิตวิทยาลัยตรวจ แจ้งผลภายใน 5 วันทำการ (ถ้าถูกส่งกลับ แก้แล้วส่งใหม่) → (4) ส่งหน้าลงนาม (ออนไลน์ใน Sign-Off Page Submission ตั้งแต่ 17 ส.ค. 2569)
- Turnitin: ตรวจบทคัดย่อ + บทที่ 1–6, ความซ้ำซ้อน **ไม่เกินร้อยละ 25**
- PDF: ห้ามสแกน ห้ามใส่รหัสผ่าน ไม่เกิน 25 MB, ฝังฟอนต์; วิทยานิพนธ์ใช้ 6 บทตามประกาศ
- ข้อผิดบ่อย: ชื่อเรื่องไม่ตรง บฑ.1, ชื่อปริญญาผิด, วันที่สอบผ่านไม่ตรงระบบ, รายชื่อกรรมการไม่ตรง, เลขหน้าผิด ฯลฯ
- หลังอนุมัติแล้ว บัณฑิตวิทยาลัยไม่แก้ไขรายละเอียดใด ๆ ให้อีก

**I. บฑ.5 ยื่นขอสำเร็จการศึกษา**
- ยื่นได้ทันทีเมื่อผลตรวจรูปเล่มอิเล็กทรอนิกส์ “ผ่าน” ทำควบคู่กับการส่งหน้าลงนามได้
- เงื่อนไขสำเร็จการศึกษา: ส่งรูปเล่มฉบับสมบูรณ์ และ **มีผลงานตีพิมพ์ตามเกณฑ์สำเร็จการศึกษา** → บัณฑิตวิทยาลัยเสนอสภามหาวิทยาลัยอนุมัติปริญญา

### 1.3 จุดตัดสินใจ / จุดที่นักศึกษามักต้องดำเนินการต่อ

| จุด | สิ่งที่ต้องตัดสินใจ / ดำเนินการ |
|---|---|
| เลือกแผน | ป.เอก / ป.โท แผน ก / แผน ข — ด่านต่างกัน |
| ผล QE | ผ่าน → ไปต่อ / ไม่ผ่าน → สอบแก้ตัวภายใน 180 วัน |
| เส้นทางหาหัวข้อ | บฑ.39 (รหัส ≤ 66) หรือ บฑกศ.39 (รหัส ≥ 67 ต้องใช้แบบนี้) |
| บฑ.1 | เลือกหัวข้อ เลือกทีมที่ปรึกษา เลือกภาษาเขียนเล่ม เลือกประเภทงาน — ภายใน 2 ภาคการศึกษา |
| จริยธรรม | เข้าข่ายวิจัยในคน → IRB ก่อนเก็บข้อมูล / ไม่เข้าข่าย → Checklist / Self-assessment |
| จังหวะยื่น บฑ.2 | รอครบ 90/45 วัน + ยื่นล่วงหน้า 15 วัน + ส่งร่างให้กรรมการ 15 วัน + เผื่อ 5–14 วันทำการ |
| ผลสอบ บฑ.2 | ผ่าน / ผ่านโดยมีเงื่อนไข (≤ 90 วัน, บฑ.4) / ไม่ผ่าน |
| หลังสอบ | นาฬิกา 21 วันเริ่มเดิน — Turnitin, PDF, อนุมัติ, ส่งหน้าลงนาม, บฑ.5 |

### 1.4 ข้อมูลที่ “ไม่พบ” บนเว็บไซต์ (ห้ามใส่ในหนังเป็นข้อเท็จจริง)

| หัวข้อ | สถานะ |
|---|---|
| การสมัคร/รับเข้าศึกษา, ปฐมนิเทศ, ลงทะเบียนนักศึกษาใหม่ | ไม่พบข้อมูล |
| จำนวนหน่วยกิตรายวิชา / รายชื่อรายวิชา | ไม่พบข้อมูล (มีแค่ “เรียนครบตามหลักสูตร”) |
| การสอบภาษาอังกฤษ — ชื่อการสอบ / คะแนนขั้นต่ำ | ไม่พบข้อมูล (มีแค่ “คะแนนภาษาอังกฤษยังไม่ผ่าน อาจกระทบ บฑ.5”) |

## 3. Story Concept

**Logline:** นักศึกษาปริญญาเอกคนหนึ่งเดินเข้ามหาวิทยาลัยวันแรกด้วยความมั่นใจ แล้วพบว่าตัวเองติดอยู่ใน “Graduate Survival” — โลกที่ทุกคำร้อง ทุกเดดไลน์ และทุกการสอบคือด่านจริงที่ต้องเคลียร์ เขาต้องเอาตัวรอดจากด่านแรกจนถึงประตูสุดท้าย พร้อมเรียนรู้ว่าเส้นชัยไม่ได้อยู่ที่ “PASSED” แต่อยู่ที่การเคลียร์ทุกเงื่อนไขให้ครบ

**Theme:** “รู้เส้นทาง = รอด” — ความยากของบัณฑิตศึกษาส่วนใหญ่ไม่ใช่ความไม่เก่ง แต่คือการไม่รู้ว่าด่านต่อไปคืออะไร ต้องใช้เอกสารอะไร และต้องเริ่มนับวันเมื่อไร

**Narrative Device:** ระบบเกม (SYSTEM VOICE) เป็นทั้ง “ศัตรู” และ “ผู้ช่วย” — มันประกาศเงื่อนไขจริงตามเว็บไซต์ ทำให้หนังมีข้อมูลที่ใช้ได้จริงฝังอยู่ในทุกฉาก

**Comedy Engine (เฉพาะคนเรียนเข้าใจ):**
1. นาฬิกาที่เดินตลอด (“ไม่เว้นวันหยุด”)
2. ความเงียบ 3 วินาทีหลังเห็นคอมเมนต์สีแดง
3. “PASSED” แล้ว…แต่ยังไม่จบ (21-DAY TIMER STARTED)
4. กาแฟที่เพิ่ม ENERGY แค่ +5%

**Emotional Arc:** มั่นใจ → ช็อก → สู้แบบวุ่นวาย → หลงทาง → ล้มแล้วลุก → หมดแรง → เผชิญหน้า → โล่ง → (หักมุมตลก) → สำเร็จอย่างอบอุ่น

**Tone Guardrails:** ไม่ล้อความยาก ไม่ทำให้อาจารย์/กรรมการเป็นผู้ร้าย (กรรมการ = “Boss” ที่ทดสอบ ไม่ใช่ทำร้าย; ในฉากจบกรรมการยิ้มและพยักหน้า) ไม่ทำให้สิ้นหวัง ทุกครั้งที่ HP ลด ต้องมีภาพการลุกขึ้นตามมา
