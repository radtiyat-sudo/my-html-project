# ระบบช่วยแยกเอกสาร

Google Apps Script Web App สำหรับแยก PDF ผลสอบรวมออกเป็น PDF รายคน (ดาวน์โหลดเป็น ZIP)
ทุกขั้นตอนทำในเบราว์เซอร์ของผู้ใช้ ไม่มีการอัปโหลด PDF ไปยัง Apps Script หรือ Google Drive

## ขั้นตอนการใช้งาน

1. **เลือกไฟล์** เลือกวิธีแยก (ตามรหัสนักศึกษา / หน้าละ 1 ไฟล์) แล้วลากหรือเลือก PDF ระบบวิเคราะห์ให้ทันที
2. **ตรวจสอบ** ตารางตรวจความถูกต้องให้ทันทีที่พิมพ์ แผนผังหน้าแสดงหน้าที่ขาด ซ้ำ หรือควรตรวจ คลิกหน้าใดก็ได้เพื่อเปิดดู
3. **ดาวน์โหลด** ได้ ZIP ที่มี PDF รายคน และไฟล์ `รายการไฟล์.csv`

ปุ่ม **↻ ล้างไฟล์ / เริ่มใหม่** ใช้ล้างทุกอย่างเพื่อเริ่มไฟล์ใหม่ (ถ้ามีการแก้ไขที่ยังไม่ได้สร้าง ZIP ระบบจะถามก่อน)

## ติดตั้ง

| ไฟล์ใน repo | ใน Apps Script |
|---|---|
| `Code.gs` | ไฟล์ `Code.gs` |
| `Index.html` | **＋ → HTML** ตั้งชื่อ `Index` |

จากนั้นไปที่ **Deploy → New deployment → Web app**

## รูปแบบรหัสที่ระบบอ่านได้

ตัวเลข 7 หลัก + รหัสสาขา + `/` หรือ `-` + กลุ่ม เช่น `6512345 CS/A`, `6512345CS-A` (รองรับเลขไทย)
ถ้ารูปแบบของหน่วยงานไม่ตรงกับนี้ ให้แก้ `ID_PATTERN` ใน `Index.html`

## ข้อจำกัด

- PDF ไม่เกิน 30 MB / 300 หน้า
- ไม่มี OCR: ไฟล์สแกนต้องกรอกรหัสเอง
- ยังไม่รองรับหลายคนในหน้าเดียว
- PDF ที่ตั้งรหัสผ่านหรือล็อกสิทธิ์ต้อง "พิมพ์เป็น PDF" ก่อนนำมาใช้
- ไฟล์ที่แยกออกมาจะไม่คงลายเซ็นดิจิทัลของไฟล์ต้นฉบับ
