# แบบประเมิน IOC สำหรับผู้เชี่ยวชาญ (Google Apps Script)

แบบประเมินค่าดัชนีความสอดคล้อง (IOC) เรื่อง **การประเมินความต้องการจำเป็นของผู้ใช้บริการที่มีต่อคุณภาพการบริการของศูนย์ MU Sport Complex มหาวิทยาลัยมหิดล**
มีข้อคำถาม 29 ข้อ คือส่วนที่ 1 ข้อมูลทั่วไป 4 ข้อ และส่วนที่ 2 SERVQUAL 5 มิติ มิติละ 5 ข้อ

- **ผู้เชี่ยวชาญ**ได้รับลิงก์ส่วนตัวทางอีเมล เปิดได้ทั้งมือถือและคอมพิวเตอร์ แล้วกด +1 / 0 / −1 ทีละข้อ
  - มีแถบแสดงว่าตอบแล้วกี่ข้อ และปุ่มพาไปยังข้อที่ยังไม่ตอบ
  - กด "ให้ +1 ทุกข้อที่ยังไม่ตอบในส่วนนี้" ได้ แล้วค่อยแก้เฉพาะข้อที่ไม่เห็นด้วย
  - เลือก 0 หรือ −1 แล้วช่องข้อเสนอแนะจะเปิดขึ้นเอง
  - ระบบบันทึกฉบับร่างไว้ในเครื่องให้เอง ส่งแล้วยังเปิดลิงก์เดิมมาแก้คำตอบได้
- **ผู้วิจัย**ไม่ต้องคำนวณเอง ทุกครั้งที่มีคนส่ง ระบบคำนวณ IOC ใหม่ลงแท็บ `สรุป IOC` และส่งอีเมลแจ้ง

## ไฟล์

| ไฟล์ | ใน Apps Script |
|---|---|
| `Code.gs` | ไฟล์ `Code.gs` (ส่วน **CONFIG** อยู่บนสุด และข้อคำถามอยู่ใน `SECTIONS`) |
| `Index.html` | **＋ → HTML** ตั้งชื่อ `Index` |

## วิธีติดตั้ง

1. สร้าง Google Sheets ใหม่ แล้วไปที่ **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจาก `Code.gs`
3. กด **＋ → HTML** พิมพ์ชื่อ `Index` แล้ววางโค้ดจาก `Index.html` → บันทึก
4. (ไม่บังคับ) แก้ `RESEARCHER` (ชื่อผู้วิจัย) และ `DEADLINE` (กำหนดส่ง) ใน CONFIG
5. เลือกฟังก์ชัน **`setupSheets`** → **เรียกใช้** → อนุญาตสิทธิ์ ระบบจะสร้างแท็บ `ผู้เชี่ยวชาญ` `คำตอบ` `สรุป IOC`
6. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ผู้เชี่ยวชาญไม่ต้องล็อกอิน)
7. กลับไปที่ชีต แล้วรีเฟรชหน้า จะมีเมนู **📋 แบบประเมิน IOC** ขึ้นมา
8. กรอกชื่อ ตำแหน่ง และอีเมลผู้เชี่ยวชาญในแท็บ `ผู้เชี่ยวชาญ` (ลบแถว "ตัวอย่าง" ออกได้)
9. ใช้เมนู **📋 แบบประเมิน IOC → 3) ส่งอีเมลเชิญผู้เชี่ยวชาญ**

| เมนู | ทำอะไร |
|---|---|
| 2) สร้างลิงก์ส่วนตัว | สร้างรหัสและลิงก์ให้แต่ละคน ใช้เมื่ออยากคัดลอกลิงก์ไปส่งทาง LINE เอง |
| 3) ส่งอีเมลเชิญ | ส่งถึงคนที่สถานะเป็น "ยังไม่ส่ง" |
| ส่งอีเมลเตือน | ส่งซ้ำถึงคนที่สถานะเป็น "ส่งลิงก์แล้ว" แต่ยังไม่ตอบ |
| คำนวณ IOC ใหม่ | คำนวณใหม่ เช่น หลังลบหรือแก้แถวในแท็บ `คำตอบ` |
| ลิงก์กลาง | ลิงก์ที่ไม่มีรหัส ผู้เชี่ยวชาญต้องกรอกชื่อเอง |

> หากแก้โค้ดหลังจาก Deploy แล้ว ให้ไปที่ **การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** เพื่อให้ลิงก์เดิมใช้โค้ดใหม่

## การคำนวณ IOC

**IOC = ΣR / N**
- R = คะแนนที่ผู้เชี่ยวชาญแต่ละคนให้ (+1 / 0 / −1)
- N = จำนวนผู้เชี่ยวชาญที่ส่งแบบประเมินแล้ว

| IOC | ผลการพิจารณา |
|---|---|
| ≥ 0.50 | **ใช้ได้** (ช่องเขียว) |
| < 0.50 | **ควรปรับปรุง** (ช่องแดง) |

แก้เกณฑ์ได้ที่ `PASS_IOC` ใน CONFIG

แท็บ `สรุป IOC` มีข้อมูลดังนี้
- รายชื่อผู้เชี่ยวชาญ คนที่ 1…N
- ตารางรายข้อ: คะแนนของแต่ละคน, ΣR, IOC, ผลการพิจารณา และข้อเสนอแนะทั้งหมดของข้อนั้น
- สรุปภาพรวม: จำนวนข้อที่ใช้ได้และข้อที่ควรปรับปรุง (พร้อมเลขข้อ), IOC เฉลี่ยทั้งฉบับ และ IOC เฉลี่ยรายส่วน/รายมิติ

คำตอบดิบอยู่ในแท็บ `คำตอบ` โดยหนึ่งแถวคือผู้เชี่ยวชาญหนึ่งคน
ถ้าผู้เชี่ยวชาญส่งซ้ำ ระบบจะเขียนทับแถวเดิม ไม่เพิ่มแถวใหม่

## แก้ข้อคำถาม

แก้ที่ `SECTIONS` ใน `Code.gs` ได้เลย ทั้งหน้าเว็บและตารางสรุปจะเปลี่ยนตาม
`code` ของแต่ละข้อต้องไม่ซ้ำกัน ถ้าเพิ่มข้อใหม่ ให้รัน `setupSheets` อีกครั้งเพื่อเพิ่มคอลัมน์ในแท็บ `คำตอบ`
